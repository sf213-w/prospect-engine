# PROSPECTOR // Breach Intelligence Dashboard

A local web dashboard for analyzing data breach news and company contact data generated by the Prospector scanner scripts.

---

## What You Need

Before using the dashboard, make sure you have run one or both of the Python scripts:

- `data_breach_scanner.py` — scans RSS feeds and produces a `breaches_DATE.json` file
- `breach_contact_finder.py` — finds company contact info and produces a `breach_contacts_DATE.csv` file

Both files are saved into a `breach_reports/` folder in the same directory as the scripts.

---

## How to Open the Dashboard

No server, no installation, no dependencies required.

1. Download all three dashboard files into the same folder:
   - `index.html`
   - `style.css`
   - `script.js`

2. Double-click `index.html` to open it in your browser

   Or right-click → Open With → your preferred browser (Chrome, Firefox, Edge all work)

3. That's it. The dashboard runs entirely in your browser.

---

## Loading Your Data

The dashboard does not read files automatically — you load them manually each session.

### Load Breach Articles (JSON)

1. Click the **LOAD BREACH JSON** button
2. Navigate to your `breach_reports/` folder
3. Select the file named `breaches_YYYYMMDD_HHMM.json`
4. The dashboard loads immediately — no submit button needed

### Load Company Contacts (CSV)

1. Click the **LOAD CONTACTS CSV** button
2. Navigate to your `breach_reports/` folder
3. Select the file named `breach_contacts_YYYYMMDD_HHMM.csv`
4. Contact data appears instantly in the Contacts tab

You can load both files in either order. Loading a new file replaces the previous one of the same type.

### Drag and Drop

You can also drag one or both files directly onto the upload area instead of using the buttons.

## Reading the Stats Bar

Once data is loaded a stats bar appears across the top showing:

| Stat | What It Means |
| - | - |
| ARTICLES | Total breach articles loaded from the JSON |
| SOURCES | Number of distinct RSS feeds that contributed articles |
| CONTACTS | Number of company rows in the CSV |
| EMAILS FOUND | Companies where at least one general email was scraped |
| REPORT PERIOD | Date the breach scanner was run |

## Navigating the Results

### Breach Articles Tab

Shows all articles from the breach scanner. Each row displays:

- **Date** — when the article was published (UTC)
- **Title** — click to open the full detail panel
- **Source** — which RSS feed it came from
- **Summary** — first 2 lines of the article summary
- **Link** — opens the original article in a new tab

### Company Contacts Tab

Shows all companies extracted by the contact finder. Each row displays:

- **Company** — click to open the full detail panel
- **Website** — links directly to the company's site
- **Email** — general contact email(s), click to open your email client
- **Security Email** — security/abuse contact if found
- **Phone** — US phone number if found
- **Address** — physical address if found
- **Breach Article** — the article that triggered the company being included

---

## Filtering and Searching

Use the filter bar to narrow results across both tabs.

| Control | What It Does |
| - | - |
| VIEW MODE | Switch between Breach Articles and Company Contacts |
| SOURCE | Filter articles by a specific RSS feed |
| KEYWORD SEARCH | Free text search across all fields — title, summary, company name, email, address etc. |
| CLEAR FILTERS | Resets all filters and shows everything |

Filters apply instantly as you type. Switching between tabs keeps your current filters active.

---

## Sorting

Click any column header to sort by that column. Click the same header again to reverse the sort order. The `⇅` icon on each header indicates it is sortable.

---

## Detail View

Click any article title or company name to open a full detail panel showing all fields for that record, including the complete summary, full address, all emails, and a direct link to the original breach article.

Press **Escape** or click outside the panel to close it.

---

## Exporting Filtered Results

Click **EXPORT FILTERED** to download the currently visible results as a CSV file.

- In Articles mode it exports: date, title, source, summary, URL
- In Contacts mode it exports: company, website, emails, phone, address, article title, article URL

The file is named automatically with today's date, e.g. `filtered_contacts_2026-04-01.csv`.

This is useful for building outreach lists from a subset of the weekly results — for example filtering by keyword to find only healthcare companies, then exporting just those rows.

## Tips

- **Multiple weeks of data** — the dashboard loads one report at a time. To compare weeks, open the dashboard in two browser tabs and load a different report in each.
- **No internet required** — once open, the dashboard works fully offline. Only the article links open external sites.
- **Finding your latest report** — files are named with a timestamp so sorting by name or date in File Explorer will put the newest at the top.
- **Empty contacts tab** — if Contacts shows nothing, make sure you have loaded a CSV file (not just the JSON). The two files are loaded separately.
- **Emails not showing** — some company websites hide their emails or use contact forms. The contact finder can only find emails that appear as plain text on the page.
