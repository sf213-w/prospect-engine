About Prospector

Breach intelligence for
security-focused sales teams.

Prospector scans security news feeds weekly, extracts affected companies, finds their contact information, and presents everything in a searchable dashboard — running entirely on your local machine with no cloud, no subscriptions, and no data leaving your computer.

How It Works
01

Scan Feeds

Run data_breach_scanner.py to scan 9 security RSS feeds for breach-related articles from the past 7 days. Saves a dated JSON report to breach_reports/.

02

Find Contacts

Run breach_contact_finder.py to extract company names from article headlines, locate their websites, and scrape contact details. Saves a dated CSV file.

03

Analyze & Enrich

Load both files into this dashboard. Search, filter, sort, and use the AI enrichment tool to have Ollama extract deeper contact info from company websites.

Weekly Workflow
Step-by-Step
1

Run the breach scanner (or let Task Scheduler run it automatically every Monday)

python data_breach_scanner.py
2

Run the contact finder

python breach_contact_finder.py
3

Open index.html in your browser — double-click the file, no server required

4

Click Load Breach JSON and select breach_reports/breaches_DATE.json

5

Click Load Contacts CSV and select breach_reports/breach_contacts_DATE.csv

6

Search, filter, enrich, and export your outreach list

Dashboard Features
📰

Breach Articles Tab

View all matched articles sorted by date. Each row shows the publication date, headline, source feed, a summary snippet, and a direct link to the original article. Click any headline to open a full detail panel. Sort any column by clicking its header.

🏢

Company Contacts Tab

View all companies extracted from breach articles. Shows website, general email, security email, phone, address, and the related breach article. Click any company name for the full detail view. Email addresses are clickable mailto links.

🔍

Filter & Search

Keyword search filters across all fields simultaneously — titles, summaries, company names, emails, and addresses. Filter by source feed using the dropdown. Filters apply as you type and persist when switching tabs. Click Clear to reset.

📥

Export Filtered

Click Export Filtered to download the currently visible rows as a CSV. In Articles mode it exports date, title, source, summary, and URL. In Contacts mode it exports all contact fields. The file is named with today's date automatically.

🤖

AI Contact Enrichment

Uses a local Ollama model to intelligently extract contact information from company websites. The LLM reads raw page text and extracts emails, phones, and addresses more reliably than regex alone. Click Enrich on individual rows, or Enrich All Contacts to process every company with a progress bar.

Before using — start Ollama with CORS enabled in PowerShell:

$env:OLLAMA_ORIGINS="*"; ollama serve
Tips & Notes
Practical Guidance
  • →No internet connection is required to use the dashboard. Only article links and AI enrichment fetch external URLs.
  • →Files are named with timestamps — the most recent report is always the one with the highest date number in breach_reports/.
  • →You can load just the JSON or just the CSV — you don't need both. The dashboard displays whichever data is loaded.
  • →The contact finder only extracts companies that follow a clear breach headline pattern. Add more to the KNOWN_COMPANIES set in breach_contact_finder.py to expand coverage.
  • →To automate the scripts weekly, use Windows Task Scheduler pointing to data_breach_scanner.py and breach_contact_finder.py.
  • →Press ESC or click outside a detail panel to close it.
  • →Some company websites block browser fetch requests (CORS policy). When this happens the AI enrichment log will show a fetch error for that row — the existing CSV data is kept.
