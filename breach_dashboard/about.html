// WHAT IS PROSPECTOR

A local breach intelligence tool
for sales and security research.

Prospector scans security RSS feeds weekly for data breach news, extracts the affected companies, finds their contact information, and presents everything in a searchable dashboard. It runs entirely on your machine — no cloud, no subscriptions, no data leaving your computer.

// HOW IT WORKS
01

Scan Feeds

Run data_breach_scanner.py to scan 9 security RSS feeds for breach-related articles from the past 7 days. Saves a dated JSON report.

02

Find Contacts

Run breach_contact_finder.py to extract company names, locate their websites, and scrape contact info. Saves a dated CSV.

03

Analyze & Enrich

Load both files into this dashboard. Search, filter, sort, and use the AI enrichment tool to have Ollama extract deeper contact info from company websites.

// WEEKLY WORKFLOW
1.

Run the breach scanner (or let Task Scheduler run it automatically)

python data_breach_scanner.py
2.

Run the contact finder

python breach_contact_finder.py
3.

Open index.html in your browser

4.

Load breach_reports/breaches_DATE.json using the LOAD BREACH JSON button

5.

Load breach_reports/breach_contacts_DATE.csv using the LOAD CONTACTS CSV button

6.

Search, filter, and export your outreach list

// DASHBOARD FEATURES

◈ Breach Articles Tab

View all matched articles sorted by date. Each row shows the publication date, headline, source feed, a summary snippet, and a direct link. Click any headline to open a full detail panel. Sort any column by clicking its header.

◈ Company Contacts Tab

View all companies extracted from breach articles. Shows website, general email, security email, phone, address, and the related breach article. Click any company name for the full detail view. Email addresses are clickable mailto links.

◈ Filter & Search

Use the keyword search to filter across all fields simultaneously — titles, summaries, company names, emails, and addresses. Filter by source feed using the dropdown. Filters apply as you type and persist when switching tabs. Click CLEAR to reset.

◈ Export Filtered

Click EXPORT FILTERED to download the currently visible rows as a CSV. In Articles mode it exports date, title, source, summary, and URL. In Contacts mode it exports all contact fields plus the related article. The file is named with today's date automatically.

◈ AI Contact Enrichment

Uses a local Ollama model to intelligently extract contact information from company websites. The LLM reads the raw page text and extracts emails, phones, and addresses more accurately than regex alone.

Before using — start Ollama with CORS enabled:

$env:OLLAMA_ORIGINS="*"; ollama serve

Keep this PowerShell window open while using the dashboard.

Click TEST CONNECTION to verify Ollama is reachable. Use ENRICH ALL CONTACTS to process every company, or click the ENRICH button on individual rows. Results update the table in place and are highlighted in amber. Note: some company sites block browser requests (CORS) — the log will indicate when this happens.

// TIPS & NOTES
  • — No internet connection required to use the dashboard. Only article links and AI enrichment fetch open URLs.
  • — Files are named with timestamps — the most recent report is always the one with the highest date number in breach_reports/.
  • — You can load just the JSON or just the CSV — you don't need both. The dashboard shows whichever data is loaded.
  • — The contact finder only extracts companies whose names follow a clear breach headline pattern. You can manually add more companies to the KNOWN_COMPANIES set in breach_contact_finder.py.
  • — To schedule the scripts to run automatically every Monday, use Windows Task Scheduler pointing to data_breach_scanner.py and breach_contact_finder.py.
  • — Press ESC to close any detail panel.
