What is Prospector?

Prospector is a local breach intelligence dashboard designed to identify companies affected by data breaches and extract actionable contact information for security analysis.

How to Use Prospector

1. The Start

Begin by running your local Python scanner scripts. This generates the necessary JSON (breach news) and CSV (contact data) files in your breach_reports/ directory.

2. How it Works (Workflow)

Open the dashboard and load your generated files. The dashboard acts as a "Single Source of Truth," aggregating disparate data into a unified, searchable interface without requiring an external database.

3. Analyze & Filter

Use the Articles tab to scan for specific keywords or industries. Use the Search bar to narrow down records across both tabs instantly to find high-priority leads.

4. Enrichment

Switch to the Contacts tab to view scraped emails and phone numbers. Use the ENRICH button to trigger local AI analysis via Ollama, which verifies company details and adds security context to each record.
